# GreenNagpur (Trees Tracker) 🌳

A modern, sleek, and highly interactive dashboard for tracking urban reforestation efforts and tree planting initiatives across Nagpur.

## Features
- **Modern Floating Dashboard**: A beautifully designed glassmorphic UI interface built on top of an interactive map.
- **Real-Time Map Visualization**: Powered by React-Leaflet, allowing users to view different planting zones with sleek custom markers.
- **Multi-Layer Map**: Seamlessly switch between Modern, Satellite, and OpenStreetMap views.
- **Detailed Metrics**: Track survival rates, overall planting progress, categorical distributions (Urban Forest, Park, Street Trees), and specific area details.

## Tech Stack
- **Frontend**: React (Vite)
- **Map**: Leaflet & React-Leaflet
- **Styling**: Vanilla CSS with custom glassmorphism utilities & Google Rubik Font
- **Icons**: Lucide React

## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```
2. **Run development server**
   ```bash
   npm run dev
   ```
